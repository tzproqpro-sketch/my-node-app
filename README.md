# Laboratory Work 23

Tasks 1-3: connection and heartbeat, CRUD, cursors, aggregation, indexes and text search.
Run npm install and npm test. Tests download and start a real isolated MongoDB server using mongodb-memory-server, then stop it.
For an existing database copy .env.example to .env and run npm run task1, task2 or task3.
The advanced example inserts one million documents in batches and compares real memory usage. It does not force an out-of-memory failure; measured results depend on available RAM.
Only temporary demonstration collections are dropped. CRUD changes are tagged and cleaned up.
