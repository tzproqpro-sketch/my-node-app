# Ответы на контрольные вопросы

1. `package.json` нужен для описания проекта: имя, версия, зависимости и команды запуска.
2. Зависимости из `package.json` устанавливает команда `npm install`.
3. `git merge` объединяет ветки отдельным merge-коммитом, а `git rebase` переносит коммиты на новую базу и делает историю линейной.
4. Число Пи без библиотек можно вычислять рядом Мачина: `pi = 16 * arctan(1/5) - 4 * arctan(1/239)`, считая `arctan` через ряд Тейлора.
